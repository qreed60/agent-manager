# Phase 1 Gate

Phase 1 is complete when:

- `~/agent-manager` exists.
- Central configs exist.
- Shared schemas exist.
- OpenHands profile directories exist.
- Runs/worktrees directories exist.
- JSON files parse successfully.
- No OpenHands settings were modified.
- No model calls were made.
- No LangGraph runtime was created.
- No target project source files were modified.
