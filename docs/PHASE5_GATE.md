# Phase 5 Gate

Phase 5 is complete when:

- `scripts/bootstrap_project_state.py` exists.
- Target project has `.agent_manager/` project-local state.
- Project-local JSON files parse.
- Only `.agent_manager/` files are changed in the target repo.
- No OpenHands run occurs.
- No model calls occur.
- No LangGraph runtime occurs.
- No source behavior is modified.
- No auto-merge or auto-push occurs.
