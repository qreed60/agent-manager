# Phase 3 Gate

Phase 3 is complete when:

- configs/agent_profiles.json exists.
- Each OpenHands profile has profile.json, system_prompt.j2, security_policy.j2, and settings.template.json.
- All profile JSON files parse.
- No OpenHands settings were modified.
- No OpenHands process was run.
- No model calls were made.
- No target project source files were modified.
